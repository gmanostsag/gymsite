# Ταχύτητα – τι αργεί το site (μέτρηση 12/11/2026, κινητό)

Δεν έχω πρόσβαση στο διαχειριστικό· τα παρακάτω προκύπτουν από ό,τι κατεβάζει κάθε σελίδα.
Πριν απενεργοποιήσεις οτιδήποτε: **κάνε αντίγραφο ασφαλείας** (SiteGround → Site Tools → Backups) και έλεγξε τη σελίδα μετά από κάθε αλλαγή.

## Μετρήσεις
| Σελίδα | Απάντηση server | Φόρτωση | Μέγεθος |
|---|---|---|---|
| Αρχική | 1,1–1,3 δευτ. | 3,2 δευτ. | 2,9 MB |
| Υπηρεσίες | 1,2 δευτ. | 2,6 δευτ. | 0,7 MB |
| Επικοινωνία | 0,9 δευτ. | 2,8 δευτ. | 1,3 MB |

Ένας γρήγορος server απαντά σε 0,1–0,3 δευτ. Το SG Optimizer ενώνει όλα τα scripts σε ένα αρχείο
**~1,1 MB** (≈280 KB συμπιεσμένο) και όλα τα CSS σε **0,7–0,95 MB** – σε **κάθε** σελίδα.

## Τι βρήκα, με σειρά σημασίας

1. **Η cache του SiteGround δεν δουλεύει (BYPASS) – αιτία: το plugin «Meta for WordPress».**
   Σε κάθε σελίδα ο server στέλνει το cookie `_fbp`, και σελίδες που στέλνουν cookie δεν μπαίνουν στην cache.
   **Λύση:** η ίδια με τα cookies (COOKIES.md, βήμα 3) – απενεργοποίηση του plugin, Pixel μέσω Complianz.
   Αναμενόμενο: η απάντηση του server πέφτει πιθανότατα από ~1,2 σε ~0,2 δευτ.

2. **Booknetic φορτώνει παντού.** Το σύστημα κρατήσεων, μαζί με Select2, Flatpickr, jQuery UI, intl-tel-input,
   είναι **περίπου το μισό ή και περισσότερο** από το μεγάλο αρχείο JavaScript – σε κάθε σελίδα, ενώ χρειάζεται μόνο στην `/book-now/`.
   **Λύση:** plugin **Asset CleanUp: Page Speed Booster** (δωρεάν) → για κάθε αρχείο του Booknetic
   «Unload site-wide» με εξαίρεση τη σελίδα Book now.

3. **Spectra (Ultimate Addons for Gutenberg) – φορτώνει αλλά δεν χρησιμοποιείται.**
   Καμία σελίδα δεν έχει μπλοκ Spectra (όλες είναι Elementor), αλλά προσθέτει ~100 KB JS και CSS παντού.
   **Λύση:** Πρόσθετα → Απενεργοποίηση «Spectra». Αν δεν χαλάσει τίποτα, διαγραφή.

4. **ElementsKit Lite – γραμματοσειρά εικονιδίων 454 KB** στην Επικοινωνία, και πολύ CSS παντού.
   Μάλλον χρησιμοποιείται για 1–2 εικονίδια.
   **Λύση:** ElementsKit → Modules → απενεργοποίηση «Icon Pack» (και ό,τι άλλο δεν χρησιμοποιείς),
   αντικατάσταση των εικονιδίων με εικονίδια του Elementor. Αν δεν χρησιμοποιείς κανένα widget του, απενεργοποίηση.
   Έχεις **δύο** πακέτα πρόσθετων για Elementor (ElementsKit + Essential Addons) – κράτα ένα.

5. **MonsterInsights – ~130 KB** για το Google Analytics.
   **Λύση:** όταν βάλεις το Complianz, ενεργοποίησε εκεί το Google Analytics 4 (`G-TGLLWQ8JBX`) και απενεργοποίησε το MonsterInsights.
   Μία δουλειά, δύο κέρδη: λιγότερο βάρος + σωστή συγκατάθεση.

6. **Εικόνες ~2,1 MB στην αρχική.** PNG 400–470 KB η καθεμία· η δωροκάρτα φορτώνει στα 1536px.
   **Λύση:** SG Optimizer → Media → **WebP: ON**, **Lazy Load: ON**. Στο Elementor διάλεξε μέγεθος εικόνας «Large» αντί για «Full».
   (Στη δοκιμή μου οι ίδιες εικόνες σε WebP βγήκαν 40–60 KB.)

7. **Γραμματοσειρές.** Roboto σε 7 βάρη + εικονίδια Elementor (106 KB) + Font Awesome (80 KB).
   **Λύση:** Elementor → Ρυθμίσεις → Features: **Inline Font Icons: Active**. Στην τυπογραφία κράτα 2–3 βάρη Roboto.

8. **Μικρά:** emoji script του WordPress (22 KB) → SG Optimizer → Frontend → **Disable Emojis: ON**.

## Σειρά που προτείνω
1. Backup.
2. Βήματα 1 και 5 μαζί με τα cookies (Complianz).
3. Βήμα 3 (Spectra) – 2 λεπτά.
4. Βήμα 6 (εικόνες) και 8 – 5 λεπτά.
5. Βήμα 2 (Booknetic με Asset CleanUp) – 15 λεπτά.
6. Βήμα 4 και 7 – όταν βρεις χρόνο.

Μετά από κάθε βήμα: SG Optimizer → Purge Cache, και έλεγχος σε ιδιωτική καρτέλα.
Πες μου όταν τελειώσεις και ξαναμετράω.
